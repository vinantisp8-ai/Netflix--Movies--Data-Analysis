# Netflix-Movies-Data-Analysis
Exploratory Data Aanlysis Of Netflix Movies Dataset using Python

# project overview:
This project focuses on Exploratory Data Analysis (EDA) of the Netflix Movies Dataset Using Python.
The Main objective is to analyze movie data, identify trends, discover patterns and generate meaningful insights through data analysis and visualization.
# project Objectives:
- Understand and explain the Netflix Movies dataset.
- Identify top-performing movies.
- Identify trends in movie releases.
- Analyze country-wise and language-wise movie distribution.
- Analyze movie genres, ratings  and  popularity.
- Explore movie trends over the years.
- Understand relationships between budget and revenue.
# tools & Technologies:-
- Python
- Numpy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
